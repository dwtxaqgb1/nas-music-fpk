# NAS歌曲下载（飞牛音乐桥接版）

基于落雪音乐(lxserver)的NAS音乐搜索、播放与下载工具，桥接飞牛音乐App。

## 主要功能

- 🔍 **音乐搜索**：多平台并行搜索（酷我/网易/咪咕/腾讯）
- 🎵 **飞牛音乐桥接**：飞牛音乐App内直接搜索播放
- ⬇️ **边下边播**：点了就播，同时存盘到本地
- 💾 **下完再播**：完整下载后播放，流畅不卡顿
- 📦 **音源仓库**：一键从GitHub拉取音源JS，支持release zip解压和tree文件列表
- 🔄 **跨平台兜底**：播放失败自动在其他平台搜索替代版本
- 📱 **手机适配**：Web界面适配手机操作

## 鸣谢

- [落雪音乐 LX-Music](https://github.com/lyswhut/lx-music-desktop) - 核心播放引擎
- [fnmusic-ext](https://github.com/) - 飞牛音乐桥接
- 各音源仓库作者

## 安装

1. 下载最新 `.fpk` 文件
2. 飞牛应用中心 → 安装 → 选择文件
3. 向导页默认值已填好，直接下一步
4. 安装完成后打开Web端，在音源管理里导入音源
5. 飞牛音乐App即可搜索播放
